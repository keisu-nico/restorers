ゲームの紹介

プレイヤーは修復士という画家になって有名な絵画の一部だけを描いて元通りに直します。作業終了後はプレイヤー全員でどこが修復された箇所か当てます。自分が描いたところは他人から当たらないようにしつつ、自分は他人が描いた場所を当てれば得点が得られます。

プレイ人数

2～8人（一人での練習モードあり）
※5人くらいでVCで話しながら遊ぶのが良いです。

あそびかた

全員が同時に、割り当てられたマスを1マスずつ制限時間内に模写します。
全員が描き終えると、原画と手描きのマスが混ざった合作が公開されます。
合作は5秒間公開されたあと推理に移ります。自分以外の人が描いたと思うマスを、30秒以内に決められた枚数だけ選びます。
得点:手描きのマスを当てるたびに+1点。自分のマスを見逃した人1人につき、1マスごとに+1点。

プレイのコツ

奥にあるものから手前にかけて順番に描く。
隣接するマスを意識して描くと溶け込みやすいです。

最初は分割数6x6、制限時間120秒がちょうどいです。
描画サポートもどちらもオンにしましょう。
